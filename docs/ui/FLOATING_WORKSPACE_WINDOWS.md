# Floating workspace windows

Chart workspace panels can be detached into floating windows. Each window supports:

- normalized, responsive position and size;
- free movement and resizing while unlocked;
- a per-window position and size lock;
- docking back into the tiled workspace;
- account-backed persistence and workspace preset backups.

Normalized geometry is used instead of absolute pixels so a locked layout remains usable when the same account moves between different viewport sizes.
