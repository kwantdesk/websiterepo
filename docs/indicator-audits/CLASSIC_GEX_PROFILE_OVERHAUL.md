# Classic GEX Profile overhaul

Catalogue item 15. This release repairs live selection, cadence and rendering. Historical replay coverage and native comparison remain open.

## Findings and repairs

- The library previously allowed adding Classic GEX on charts the request path could never serve. Library and workspace now share the NQ/MNQ recorded-futures check. Changes to contract, options source, expiry, profile type or manual mapping clear superseded data. The response must match the current options selection and mapping before it can paint.
- A visual style change used to clear the ladder and its accumulated lookbacks. The effect now keys on data and mapping settings only, uses the existing workspace cache for identical requests, honours the provider's refresh interval and pauses reads in hidden tabs. The user interval is a minimum, so it can request slower updates. No active live profile remains when replay starts. An already in-flight shared request may finish for other consumers, but its response is ignored after replay begins.
- The native majors feed requests NQ/NDX 0DTE. It previously replaced mapped levels on QQQ, other expiry scopes and manual charts. Native values now appear only on the matching NQ/NDX live automatic 0DTE selection and the same New York session. A generic zero-gamma fallback also ignored Classic's expiry scope, so it has been removed. The chart still uses verified mapped major levels where available, and zero gamma stays empty where the matching source supplies none.
- The old nearest-snapshot lookup could show a newer value for an older lookback. Each dot now chooses the latest observation at or before its target, with a 90-second coverage tolerance. The ten-minute dot joins the existing 1, 5, 15 and 30-minute dots.
- Tooltip session volume formerly took one maximum per strike and side, hiding other observed expiries. It now deduplicates cumulative snapshots per expiry and side before adding distinct contracts at a strike. Counts are labelled observed volume. Next expiry no longer falls back to the current expiry when a later expiry is absent. The tooltip also uses the chart timezone and actual host symbol.
- An uncalibrated automatic 1:1 mapping no longer paints the options ladder on the futures price axis. The status badge explains the pending calibration or empty expiry scope. Manual mapping controls are disabled while automatic mapping is active, and the zero-gamma colour control is disabled when its line is hidden.
- The width control used to flatten out on narrow panes. The renderer and hover targets now share the same percentage of actual plot width and cap each bar to its side of the ladder.

## Verification

- 22 focused checks passed, including the actual workspace effect's provider cadence, exact request key, replay transition and rejection of an in-flight result. The suite covers source scope, manual multipliers, observed counts, all lookback targets, compatible roots, native-level eligibility and narrow ladder width.
- An isolated Chrome fixture rendered the native ladder with four hover targets, displayed the contract counts and Brisbane time in its tooltip, switched the profile edge and logarithmic display, preserved the selected Manual mapping through settings normalization and removed current profile rows in replay. In a 330-pixel panel, the largest hover target grew from 8.72 to 49.05 pixels when the width setting changed from 8% to 45%. The fixture used deterministic inputs and reported no browser errors.
- Static REA found no Gamma/GEX-named methods in the 87 retained methods from DeepChart's installed indicator-description type. This is limited metadata and cannot establish the native implementation. [DeepGamma heatmap documentation](https://www.deepcharts.com/helpcenter/deepgamma-web/article/option-gex-heatmap-deepgamma-web)
- GexBot's published Classic method sums contract gamma weighted by volume or OI and documents native majors, spline zero and lookback controls. KwantDesk's QuantData volume surface remains a flow/OI-scaled estimate. Its all-expiry request also differs from the reference's published 90-day full category. [GexBot Classic](https://docs.gexbot.com/classic/gexbotclassic/) [GexBot Classic API](https://docs.gexbot.com/apidocs/classic/)

## Remaining checks

- Read-only production probes found the website API access gate (401), the normalized VPS Classic proxy unavailable (503), and the native majors gateway rejecting the credential used (401). They did not expose a same-timestamp provider ladder. Full live calculations, request cadence in production, GexBot parity and complete historical scope remain unverified.
- Replay continues to exclude the current-only profile. A separate recorded provider profile adapter is required before replay can display historical ladders. The documented Classic Chain returns net volume and OI per strike, so its archived net value alone cannot recover split call and put bars. [Classic Chain response schema](https://docs.gexbot.com/apidocs/classic/classic-chain/) The closed-session status remains conservative until the exact completed profile can be confirmed. DeepChart desktop verification remains deferred.
