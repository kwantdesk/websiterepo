# Gamma Environment ticker selection

The owner wants to choose the ticker whose gamma regime is calculated, and to identify that ticker on the chart.

Clicking the Gamma Environment badge now opens that pane's existing indicator settings, activating the pane first. A themed Gamma ticker selector offers Automatic plus ES, NDX, NQ, QQQ, SPX, SPXW and SPY, the existing supported options-frame sources. Explicit choices resolve their own frame independently of the chart instrument and do not change the chart or Kwant Levels settings. Automatic preserves the existing cash-source/futures-overlay routing. The badge identifies the explicit ticker immediately, or the actual automatic overlay calibration source when available. Existing refresh, matching-source protection, stale retention and source-error behaviour remain. Saved selections normalize and persist with the indicator.

Verification: three permanent tests cover all seven explicit sources across ten chart families, prior Automatic behaviour and saved-setting normalization. An isolated headless browser mounts the actual settings control and the badge JSX extracted from Chart, checks click-to-settings, themed selection and immediate ticker identification, with no page errors or external requests. Scoped library lint and full production build pass; final build repeated after the accessible picker-label addition. The older gamma-environment-indicator suite has two pre-existing source-pattern failures (the gamma prop expression and old quote timestamp comparison), reproduced against HEAD; no provider accuracy claim is inferred from those static tests.

No VPS restart, account changes, historical backfill, indicator source-code display option or additional provider subscription. Explicit selection uses the existing gamma request cache and refresh policy. Replay acquisition itself is outside this source-selection change and retains its existing behaviour.
