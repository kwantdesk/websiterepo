# Late executions, candle gaps and disappearing wicks

Confirmed frontend defect: applyInstitutionalTradesToCandles dropped every clock execution older than the latest bucket. A fast rollover could therefore discard the closing minute high/low. Its first-arrival open also did not account for an earlier exchange-timestamped print arriving later. The direct Chart flush discarded old candle paints as well.

Changes: binary-route late prints into their actual clock bucket; retain chronological source-watermark opens/closes; keep seeded historical opens; preserve complete archived close/volume when a partial late print only proves additional extrema. Insert missing interior buckets only from received executions. Paint batches start at the earliest touched bucket. Existing older candles receive historical series.update calls without moving the live cursor or Footprint tail backwards; newly inserted interior bars trigger structural history redraw. Event chart logic is unchanged.

Negative control on original code lost a high of 20010 and low of 19995 (held 20002/20000). New regression tests cover that rollover, out-of-order first prints, seeded opens, real-print-only interior gap recovery and the actual Chart flush callback. Candle suites: 41 pass, two stale source-regex assertions fail; the same two failures reproduce against original HEAD source. Final production build passed.

Read-only live VPS audit: 20 completed NQ one-minute OHLC bars matched 3666 recorded live executions with no differences. Evidence: docs/audits/2026-11-02-nq-candle-integrity.json. This bounded sample does not prove every historical candle or the exact unspecified bars reported by the owner. Genuine jumps between successive trades can leave inter-bar gaps and a bar whose high/low equals its body legitimately has no wick. No synthetic prices are added. No provider history requested, data rewritten, account changes or gateway restarts. One scoped main/yfmi release with Ready/public commit verification.
