# Prompt / fix / outcome — Price Movement Levels

## Prompt

The owner reported that many indicators were still Pending and asked for each
one to be genuinely engineered using DeepCharts and the licensed DLL, rather
than left as a placeholder.

## Fix

Converted Price Movement Levels from Pending into a real exchange-session
overlay. Added future-safe Open/prior-Close anchors, percentage and instrument-
tick spacing, dynamic minimum levels, three independently styled line groups,
level labels, custom exchange-time sessions, theme/custom colors, persistence,
templates, deep-history routing and explicit gap boundaries.

## Outcome

The indicator can now be added and configured from its complete observed
settings surface. Seven focused tests and shared slider/template/theme gates
pass. The catalogue audit is down from 19 to 18 Pending entries. Protected
DeepCharts internals and the web renderer's 1–4 line-width limit remain stated
plainly in the audit rather than being presented as exact parity.
