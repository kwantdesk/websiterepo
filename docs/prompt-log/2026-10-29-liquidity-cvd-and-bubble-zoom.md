# Liquidity Map: CVD presentation and zoom-stable executed bubbles

Owner requests: CVD offers Line/Bars only; remove its settings shortcut, Live button and NET/LOADED legend; remove the flashing live-edge projection and use smooth drawing. Additional request: zoom must not regroup the same executed trades, change their colours/volumes, or move their market anchors.

## Findings and changes

- CVD's newest timestamp returned the entire CVD canvas width, while interior points used the map's narrower data span before its live gap. A new execution therefore jumped into the right-hand gap, then returned on a later frame. All timestamps now project through the map's actual `layout.xForIndex`, including both endpoints. The right-rail CSS margin is synchronized before fitting/painting the CVD canvas, avoiding an initial stretched backing store.
- Removed the CVD header's Candles choice, settings shortcut, Live button and NET/LOADED text, along with their listeners and DOM writers. Old persisted candle/unknown styles normalize to Line; explicit Bars remains supported. Other global map navigation and settings are preserved.
- A display-only live-tip/range easing state redraws the CVD canvas between actual packets. It retargets without overshoot and settles within 200 ms of an unchanged target (35 ms exponential response). Animation alone does not repaint the heatmap/DOM, create market frames, modify CVD history, or change timestamps/volume. Paused/history/replay views snap to exact data; source-session, book or projection changes reset presentation. Line and Bars share the aligned edge.
- Bubble clustering previously used current zoom pixels AND the visible start index as inputs/cache keys. It now uses a per-book default reference scale held independently of pan/zoom, and all retained causal history through the selected end cursor. Only visual projection and sphere size respond to zoom. Actual trade identity/anchor, buy/sell ratio, total and minimum-contract filters do not change. Newly exposed offscreen history and genuinely evicted history still follow the loaded time window.
- Reviewed the prior safeguards in `2026-09-07-liquidity-map-bubble-anchors.md`, `2026-10-27-liquidity-map-bubble-stability.md` and `2026-10-28-liquidity-smart-bubble-volume.md`. The broad full-map rollback had removed fixed source-time cluster windows and fixed volume sizing. Restored only that 77-line engine diff from `3767618f` (no heatmap raster, DOM, palette, replay or provider changes): bounded clustering strength, 250–4,000 ms nested gross windows, local window references and 250 ms differential cancellation windows. Incremental refresh includes whole source windows, so an absent balanced net group cannot reappear as one uncancelled side.
- Sphere volume uses a fixed 100-contract sizing reference; sizes no longer normalize against whichever groups happen to be rebuilt/visible or cap large trades to identical diameters. Earliest actual execution anchors and exact totals remain intact. Gross is the new/reset default; explicit saved differential choices remain honored. Culling uses the projected radius. Cache checks distinguish replaced books even when counts/revisions match.
