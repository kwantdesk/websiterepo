# Prompt log

Every request Jacob makes gets a file here: his words verbatim first, then what
was actually done about them, written when the work is finished.

**Why:** so progress can be read back later and corners can be checked for. A
summary written from memory after the fact is exactly where corner-cutting
hides — the prompt is recorded *before* the work starts, so the answer has to
be measured against what was actually asked rather than against a convenient
retelling of it.

## Rules

- One file per prompt: `YYYY-MM-DD-NN-short-slug.md`.
- The prompt is copied **verbatim**, typos and all. It is never tidied,
  paraphrased, shortened, or split up.
- The answer is written when the work is done, and says what was verified and
  what was not. Anything left unfinished is listed as unfinished.
- Files are `.md` under `docs/`, so they never trigger a production build.
