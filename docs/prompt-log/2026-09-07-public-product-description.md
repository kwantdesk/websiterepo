# Public product description

## Prompt

Chrome described Kwant Desk as a “private quant research workspace,” which is
not what the product is. Reword it.

## Fix

Updated the root browser metadata and installable web-app manifest to describe
Kwant Desk as a professional trading platform for charts, order flow, options
analytics, market intelligence and execution. Removed the same private
research wording from the login screen and its configuration error.

## Outcome

Chrome, installed-app surfaces and the login page now use customer-facing
trading-platform language instead of describing Kwant Desk as private research.
