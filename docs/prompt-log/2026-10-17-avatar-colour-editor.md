# Per-colour console avatar customisation

Owner requested an editable swatch for every visible colour, stock colours
alongside individual resets, recent colours to the right, interactive preview
and persistent saved results. This applies to all thirty built-in avatars.

Offline preprocessing identifies background separately from enclosed details,
extracts each foreground palette and maps every pixel to two weighted palette
colours. Original WebP artwork is never modified. The runtime adds palette
deltas to source pixels, preserving texture, shades and antialiased boundaries;
stock/reset produces exactly the original pixel bytes, not a posterized image.
Current avatars expose four to seven editable paint colours including background
and outline. Shading blends share their parent paint swatch, not hundreds of
individual near-identical raster-pixel RGB controls.

The editor uses the existing colour picker, a RAF-coalesced 500px circular canvas,
stock/reset buttons and existing account-tracked recent colours. Only the selected
source/map pair loads; thirty static map files total 703,975 bytes and use the
existing public-images middleware exclusion. No image-generation service calls,
provider calls or server uploads happen during colour dragging.

Save Profile awaits the latest colours (independent of the last painted frame),
exports a bounded 500px WebP, and writes it with validated avatarAppearance
metadata through the existing identity/profile flow. Reopening restores editable
colours; unchanged saved avatars reuse their current image. Reset exports the
original stock URL. Uploading a photo clears preset metadata. Failure preparing
the image stops saving with an explicit error; no false success is reported.

Verification: 15 focused tests cover all thirty masks/colour assignments, exact
stock reset, independent/weighted colour changes, alpha preservation, profile
JSON roundtrip and validation, component live/latest-state export, stock/recent
controls, real Save-handler ordering/error path and prior upload/preset behaviour.
Scoped lint has zero errors and two existing unrelated img warnings. Isolated
production build is checked before release. Colour kernel ~3–5ms per avatar on
this machine; not a signed-in browser, slow-device or concurrent-load result.
Visual raster review: docs/avatar-art/console-colours-review.webp, generated by
scripts/review-social-avatar-palettes.mjs. Authenticated browser/cross-device
roundtrip is still unverified. Existing history/feed recovery and live-load launch
verification remain separate open platform work.
