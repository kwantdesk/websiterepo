# Bid/ask history traces at compressed zoom

Owner reports historical bid/ask lines appear unusually close together. Investigation compared renderer history and sampled existing VPS NQ/ES snapshots read-only; no reset or subscription changes. The latest CVD-only release did not change the inside-market drawing method. Four samples per instrument returned valid BBO-sourced books: NQ spread 3–4 ticks and ES spread 1 tick. This sample does not certify every archived quote or the owner's current viewport.

Confirmed a rendering weakness at compressed scales: both traces and dashed extensions used fixed 3px strokes, which overlap when a real spread projects to less than 3px. The actual inside-market method now chooses stroke thickness from the smallest positive visible quote gap, capped at the original 3px and floored at 0.5px. All bid/ask coordinates and quote values remain exact. Below pixel resolution the lines can still appear close; this change never invents a minimum price gap. Normal spacious zoom retains the original thickness.

Added actual-method regressions proving tight quotes use non-overlapping ink where resolution permits, exact quote/time coordinates and extensions remain, normal zoom retains 3px, subpixel quotes are not shifted, only visible quotes control thickness, and history remains unchanged. No reconstruction/widening of saved quotes, no heatmap/DOM/bubble data changes, no feed restart, and no recording/trade/account/VPS changes.
