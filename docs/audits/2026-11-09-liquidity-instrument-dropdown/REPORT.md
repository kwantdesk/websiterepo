# Liquidity instrument dropdown — 9 November 2026

Replaced the centred modal instrument picker with a compact, anchored nonmodal dropdown shared by the standalone liquidity map and embedded Charts panels. It retains the original instrument filtering, available-instrument catalogue, tab persistence and symbol-selection handlers. The menu is at most 340 × 360 px, adapts to available viewport space, and keeps its position and height while searching. Click-away, Escape, close and trigger-toggle dismiss it. Escape returns focus to the trigger. Only the instrument picker changes; other settings dialogs remain as they were.

The phone controls drawer closes when this dropdown opens so its backdrop does not remain behind the instrument list. The native dialog uses show(), not showModal(): the chart is not dimmed or made inert. Styles use the existing theme variables and remove the centred geometry for this picker only. No renderer, depth-book, feed, order or account changes.
