# Market Map time scrubbing — 9 November 2026

Confirmed causes: snapshot changes changed the request identity and cleared the stage, producing the full loading screen. The released Market Map renderer also had no incremental snapshot updater, so each response rebuilt its canvas. Snapshot responses replaced the time slider while it could still be held by a pointer.

Repair: retain the map only for time changes within the same request/filter/session scope; update observations and summary on the same canvas, preserving zoom and camera. Retain the time selector for an unchanged timeline, and defer timeline replacement while it is held. Cancel superseded requests as soon as a new time is selected. Exact historical snapshots already observed in this panel are reused immediately through a bounded in-memory LRU (32 frames / 8 MiB); no history interpolation or speculative provider prefetch. Uncached times retain the existing 220 ms request coalescing and await genuine data. The selected time control remains at the requested time while the existing map's source timestamp remains unchanged until its response arrives. Same-session master replay advances no longer forcibly clear the Market Map before scope validation.

Validation: isolated headless Chrome with deterministic test-only market snapshots and a deliberately delayed 650 ms historical API. Verified no loading overlay, held time-slider identity, canvas identity, changed historical pixels, and backward cached seek without another request. Thirteen unit / auxiliary-history tests pass, including filter/session isolation and cache limits. Syntax check passed. The browser test serves the exact staged release app rather than unrelated dirty application changes. No gateway/feed restart, owner-tab refresh, order/account changes, extra live polling or infrastructure spend.

Evidence: checks.json and market-map-replay.png. Fixture values are not live market evidence. This fixes the GEX Data Market Map tool; it does not add missing source recordings or change the separate GEX exposure-map page.
