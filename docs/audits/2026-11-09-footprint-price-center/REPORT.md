It projects the actual latest displayed quote (or latest authoritative candle close when no quote/replay), measures the current chart pane height minus the real top/bottom docked studies, and translates the fitted price range so that price lands at the usable pane midpoint. No continuous follow/lock: autoscale is false and subsequent vertical dragging remains available. Other chart types retain their existing fit-visible behavior.

Callback reads current refs for quotes and pane heights, so chart resize, indicator pane resize, live/replay transitions and later quotes do not use initialization-time geometry.
